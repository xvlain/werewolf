# 狼人杀 · 12人标准局

网页版狼人杀，12 人「预女猎白」板子。支持**单人 vs 11 AI** 与 **Supabase 多人联机房间**。

在线体验：https://xvlain.github.io/werewolf/

## 特性

- **零框架零构建**：原生 HTML/CSS/JS，classic script 加载，`file://` 双击即玩
- **12 座位环形对局桌**：暗夜主题，桌面与移动端双端自适应
- **第一人称视角**：只见自己的身份与公共信息，完整还原信息不对称博弈
- **上帝观战模式**：一键显示全场身份，用于复盘与调试
- **完整规则实现**：夜晚技能结算、同守同救、女巫不可自救、白痴翻牌免死后不可再被放逐、
  猎人被毒不能开枪、警长 1.5 票归票、出局翻牌公开身份、屠边双胜利条件
- **AI 经过 15000 局模拟调优**：好人胜率 48.1% / 49.1% / 49.3%（三轮独立复核），
  稳定落在 45%–55% 健康区间

## AI 建模的核心机制

| 机制 | 作用 |
|---|---|
| 票型分析 | 狼人投票天然同步，翻牌确认一只狼后回溯历史票型锁定队友（单点收益最大） |
| 站边与警徽 | 对跳局面下好人以警徽为公共信号收敛站边 |
| 接力带队归票 | 预言家阵亡后由女巫/猎人起跳接管归票，避免好人票型分散 |
| 金水/银水保护 | 已确认的好人不会被子己方误投 |
| 悍跳与倒钩 | 狼人冒充预言家对跳、制造替罪羊误导好人 |

## 目录结构

```
index.html          入口（主菜单 / 大厅 / 对局 / 结算 / 规则）
css/style.css       样式
js/engine.js        规则引擎（纯结算）
js/ai.js            AI 决策系统
js/config.js        Supabase 与板子配置
js/net.js           联机层（RPC + Realtime + 轮询兜底）
js/ui.js            渲染与交互
sql/                联机后端建表脚本
tools/devtest.html  自动化冒烟测试
```

详细部署与验证流程见 [RUNBOOK.md](RUNBOOK.md)。

## 联机后端

联机需要先在 Supabase SQL Editor 执行 `sql/werewolf_schema.sql`。
身份分配与夜晚结算全部在 Postgres 函数内完成，`wr_roles` 表不开放任何 SELECT 策略，
客户端永远拿不到完整身份表。
